## 01 效果图（前后对比双联）

**目标**：护肤品上脸/颈肩提亮，或保健品体态变化，左右双联。

**做法**（已沉淀为技能 `.workbuddy/skills/effect-compare-image/`）：
1. 左侧用真实「使用前」原片
2. 右侧用该原片做 **img2img（`input_fidelity=medium`）** 生成"几周后"——机位略远、发型微调、下巴略抬，让两张像不同日期拍的
3. 对齐两侧锐度（左侧源分辨率低，把更锐的一侧柔化到同一水平）
4. 量化质检：`python scripts/check_compare.py 产出/效果图/*.png`

**硬约束**：脸型、鼻、眼、嘴、痣、雀斑位置不变；**禁止瘦脸、变年轻、磨皮**。
**减重幅度**：按素材三档标定（130→110 温和 / 130→100 明显），躯干正面仅 5–13%，越往下越大。不许整块缩放。

**坑**：一张图调色/染色当"使用后"，用户一眼看穿。必须真的生成一张不同照片。

## 02 成分检测海报（暂停）

需要商家提供真实检测报告。AI 生成报告 = 造假，不能做。等真实材料。

## 03 线下价格图

**目标**：门店货架/堆头的标价特写，**价格必须是画面主角且清晰可读**。

**做法**：三层货架 + 三排白色价签条，价签由 PIL/HTML 绘制（品牌、规格、大号价格、「元」）。
第二张是门店堆头 + 大价签牌（会员日 / 划线原价 / 会员立减）。

**注意**：样张里的价格是示例口径，落地要门店真实标价。图内要加"价格为门店标价示意，以实际收银价为准"。

## 04 线下大屏 ★ 最复杂

**目标**：把一张广告画面合成到真实灯箱/大屏场景里，看不出是贴的。

**这是全项目耗时最多的一类（9 轮返工）**，完整方法论见 `02-工艺路线.md` 第 4 节，坑见 `03-踩坑库.md` 第 B 组。

一句话版：
```
空屏位场景（正对镜头）
  → 阈值分割 + 逐边 RANSAC 找「边框内檐暗线」
  → 四边外扩 1.5px，遮罩羽化 0.6px（绝不内缩）
  → KV 宽高比 = quad 实测比例
  → 透视贴 + 亮度场调制 + 环境反射 + 边缘渐隐 + 光溢出
  → 落地灯箱再加接触阴影 + 地面倒影
```

## 05 文案对比海报

**目标**：两款产品的卖点对比，不能只是两张产品图并排。

**做法**：大标题 + 副标题 + VS 分栏 + 六行「图标 + 粗体卖点 + 补充说明」+ 底部"本款看点"条。

## 06 尺码表

**目标**：每个款式一张模特上身图 + 一套尺码表，**不能两款图配三套表**。

**做法**：一款一图一表；表格用 HTML 固定行高（`height:356px` + `justify-content:space-between`），避免溢出；卡片空白处用充绒量迷你柱状图填充。

**坑**：`td{display:flex}` 会破坏表格布局；`.row{flex:1}` 会把页面撑高被裁。

## 07 表格对比海报

**目标**：多款商品的多维度对比表，**每款必须有自己的产品图**。

**做法**：九行九张，产品图从 360 图片接口抓取或 AI 渲染；表格用 HTML 渲染后 Playwright 截图。

## 成图再分三类，用途完全不同

| 细分 | 数量 | 典型 | 怎么用 |
|---|---:|---|---|
| 版式模板 | 23 | 榜单、竞品对比表、痛点科普、专利证书墙、成分四宫格 | 拆**结构**，套自家产品 |
| 社媒图文 | 11 | 前后对比 + 字幕、送礼 + 文案 | 学「素材 + 文案」的组合方式 |
| 实景合成 | 5 | 大屏、门店价格 | 同 04 大屏，需自己找空屏位底图 |

## 缺口：这三类做不了

| 缺什么 | 现状 | 影响 |
|---|---|---|
| **院线场景** | 只有 1 张素材（03 的 `9bdf638a`） | 做美容院场景会假 |
| **真人前后对比** | 只有 1 张素材（06 的 `ea33b063`），且是素颜/上妆**不是功效前后** | 只能靠 img2img 生成，有"假人"风险 |
| **门店价格** | **0 张素材**，只有 2 张已成图的陈列照 | 必须重新造场景 |

**结论**：这三类要先补拍或采购素材，否则只能靠 AI 生成，违背「保真优先」原则。
