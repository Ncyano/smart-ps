# 05 · 资产索引

> **什么时候读**：想找"有没有现成脚本"、"上一个类似的图是怎么做的"。
> **原则**：先找现成的，不要重写。这个项目里 7 类需求的做法都已经固化成脚本。

---

## 一、最有价值的代码：`产出/需求样张/`

这 12 个脚本是 7 类需求的完整实现，**新需求优先在这里找可复用的**。

| 脚本 | 干什么 | 复用价值 |
|---|---|---|
| `_build_screen.py` | **★ 04 大屏一键构建**：两张场景 + 定框 + 贴屏 + 去水印 + 地面倒影 | 最高。所有广告位合成从这改 |
| `_screen_kv.py` | **★ KV 排版 + 透视贴屏**：`make_kv()` 排画面，`warp_onto()` 做光影融合 | 最高。融合参数全在这 |
| `_floor_reflect.py` | 地面倒影 + 接触阴影 | 高。任何落地物都用得上 |
| `_cut_bottle.py` | **★ 白底产品图抠图**：投影剔除 + 实心化 + 去白边 + 轮廓压暗 | 高。所有产品图都要过一遍 |
| `_build_pair.py` | 01 效果图双联合成 | 中 |
| `_gen_compare.py` | 05 文案对比海报 | 中 |
| `_gen_compare_table.py` | 07 表格对比海报（九款九图） | 中 |
| `_gen_size_chart.py` | 06 尺码表（一图一表 + 迷你柱） | 中 |
| `_price_shelf.py` | 03 货架价格特写 | 中 |
| `_price_sign.py` | 03 门店堆头大价签 | 中 |
| `_gen_detect.py` | 02 成分检测（已暂停） | 低 |
| `_clean_models.py` | 模特图清理 | 低 |

**典型调用链**：

```bash
# 04 大屏（一条命令出两张，含倒影）
python 产出/需求样张/_build_screen.py

# 换产品图后重建
python 产出/需求样张/_cut_bottle.py      # 先抠图 → _products/bottle_v3.png
python 产出/需求样张/_build_screen.py    # 再构建
```

## 二、产线后端：`server/app/`

| 文件 | 作用 | 改它的场景 |
|---|---|---|
| `config.py` | **★ API Key 填入口** + 配置读写（`DEFAULT` 字典） | 加配置项 |
| `engines/base.py` | Engine / Capabilities / GenRequest 契约 | 加新引擎前先看 |
| `engines/seedream.py` | **★ 火山方舟适配器**（`_build_body` / `_parse`） | 接口变更只改这两个函数 |
| `engines/mock.py` | 本地确定性引擎（0 元、不联网） | 离线开发 |
| `engines/registry.py` | 引擎注册、路由、不可用回退 | 多引擎路由 |
| `pipeline/steps.py` | 度量与确定性回正（影调/饱和/锐化/评分） | 调评分逻辑 |
| **`pipeline/fidelity.py`** | **★ 保真分档 A/B/C**：主体模板匹配 + 比例 + 清晰度；object/patch 双模式 | 改质检口径（改完必跑 bench_fidelity） |
| **`pipeline/judge.py`** | **语义判定（视觉模型）**：同一款产品 / 文字乱码 / 比例；未开通则降级"未校验" | 开通模型后自动生效 |
| **`pipeline/category.py`** | **★ 品类一致性**：文案 vs 素材的品类冲突（气垫霜配「每天一粒」），**生成前**拦截 | 加新品类先补词表 |
| **`rights.py`** | **★ 授权与交付范围**：owned/licensed/third_party/sample/unknown 五级；内部参考会在导出目录留说明文件 | 改交付口径 |
| **`templates/base.py`** | **★ 工艺模板契约**：提示词追加 / 画布 / 导出 / `apply()` / 版本号 / `reframes` | 加模板先看这里 |
| **`templates/builtin.py`** | **三个内置模板 + 两个后处理**（白底重排、卖点图排版） | 改模板行为 |
| `templates/layout.py` | 排版算子：字体 / 折行 / 自动缩号 / 渐隐底 / 角标 | 改版式细节 |
| `pipeline/pack.py` | 素材打分、参考图打包、提示词组装 | 改提示词策略 |
| `pipeline/run.py` | 六步编排 | 改流程 |
| `store.py` | `data/` 落盘、批次读写 | 改存储 |
| **`jobs.py`** | 进程内任务队列：线程池 + 状态机 + `job.json` 落盘 + 启动恢复 | 改并发/状态 |
| **`export.py`** | 导出：cover 裁切 + 尺寸预设 + 导出记录 | 加平台规格 |
| `main.py` | HTTP 服务 + 路由（仅标准库） | 加接口 |
