# 06 · 术语表

> **什么时候读**：看代码或读其它文档遇到不认识的词。

---

## 图像合成

| 词 | 含义 |
|---|---|
| **KV** | Key Visual，广告主视觉。这里指"要贴进屏幕里的那张广告画面"（1080×2000+ 的竖版图） |
| **quad** | 四角坐标，`[(左上), (右上), (右下), (左下)]`，定义 KV 要映射到场景的哪个四边形 |
| **画面开口 / 内檐** | 灯箱上"边框内檐"与"可显示区域"的分界。内檐是一圈 6–20px 的浅灰带，**必须被广告盖住**，否则就是漏光 |
| **透视变换** | `cv2.getPerspectiveTransform` + `warpPerspective`，把矩形 KV 贴合到任意四边形 |
| **遮罩（mask）** | 决定"哪部分用 KV、哪部分保留场景"的二值图 |
| **羽化（feather）** | 对遮罩做高斯模糊，让边缘过渡柔和。**本项目 0.6px，多了会漏光** |
| **摩尔纹（moire）** | 屏幕像素与相机传感器干涉产生的细密纹路，用正弦函数合成 |
| **光溢出（spill）** | 屏幕的光照亮周围墙面/地面的效果 |
| **光池** | 产品底部的椭圆高光，像产品站在一滩光里 |
| **接触阴影（AO）** | 物体与地面接触处的一圈暗影，缺了物体会"浮" |
| **倒影（reflection）** | 抛光地面/玻璃上物体的镜像 |

## 融合参数（`warp_onto`）

| 词 | 含义 | 调大的后果 |
|---|---|---|
| `lift` | 黑位抬升，模拟屏幕的最低亮度 | 屏内发灰 |
| `ambient` | 全局背光透射（整块面板的底光） | 整块发灰，最危险 |
| `env` | 环境漫反射（场景强模糊后叠加） | 细节被冲淡 |
| `gamma` | 中间调提亮曲线 | <1 变亮但保留黑位 |
| `blur_kv` | 贴图前景深模糊 | 调到 0 = 锐利贴纸，一眼假 |
| `refl` | 玻璃环境倒影强度 | 过高像镜子 |
| `backlight` | 背光衰减（灯管在中间，越靠边越暗） | 边缘过暗 |
| `edge_dark` | 最边缘亮度系数 | 过低出现暗边框 |
| `edge_w` | 边缘压暗的宽度（px） | 过大边缘一圈发暗 |
| `band` | 顶部灯管反射带强度 | 出现明显亮条 |
| `tex` | 摩尔纹 + 像素噪声强度 | 噪点脏 |

## 生成与抠图

| 词 | 含义 |
|---|---|
| **img2img** | 图生图，给一张参考图让模型在其基础上变 |
| **input_fidelity** | ImageGen 的保真档位：`low` / `medium` / `high`。**medium 是唯一可用档** |
| **unmatt** | 去除半透明边缘残留的背景色（`fg = (comp - (1-a)*bg) / a`）。**alpha 小时误差放大 3–10 倍，本项目中已弃用，改「实心区颜色外延」** |
| **最大连通域** | `connectedComponentsWithStats` 取面积最大的连通区域，用于剔除投影/杂点 |
| **RANSAC** | 随机采样一致拟合，用来从带噪点里拟合直线。**本项目测四角的标准工具** |
| **探针区（probe）** | 质检时取样判断的区域（四角、顶部），对应 `bg_probe_corner` 等参数 |

## 产线

| 词 | 含义 |
|---|---|
| **六步产线** | 题图分组选优 → 参考图打包 → 多候选生成 → 三项评分 → 确定性回正 → 质检判定 |
| **批次（batch）** | 一次生成任务，落在 `data/batches/<id>/` |
| **候选（candidate）** | 一次生成产出的一张图，带三项评分 |
| **exemplar** | 参考图（往期例图），用于让模型学风格 |
| **materials** | 素材图（产品原图等） |
| **StyleProfile** | 从例图统计出的风格画像（影调分位、饱和、高频能量、背景白度） |
| **fidelity / style / quality** | 三项评分：内容保真 / 风格贴合 / 技术质量 |
| **structure / spread / sharp** | 保真三信号：主体结构吻合度 / 比例偏差 / 主体区域清晰度 |
| **A/B/C 档** | A 可信（三项都过关，可直接用）/ B 存疑（值得人看一眼）/ C 不可用（有硬伤） |
| **object / patch 模式** | 素材是单主体时走 object（三项全测）；工厂图这类多实例场景走 patch（只测特征在不在，上限 B） |
| **工艺模板（template）** | 一类图的做法打包：提示词约束 + 画布 + 导出规格 + 确定性后处理。现有 `scene` / `white_bg` / `kv` |
| **reframes** | 模板标记：该模板会主动改画幅/主体占比（白底重排、卖点图裁切）。为真时保真判定要关掉"比例"那一项 |
| **版式自检（layout）** | 模板后处理的自检结果：文字是否装得下、背景是否达标。`ok=false` 时该候选最高只能给 B |
| **确定性回正** | 用固定算法（影调、饱和、锐化）校正，不依赖模型 |

## 质检

| 词 | 含义 |
|---|---|
| **A 级硬指标** | 自动拦截项（画布、中缝、背景边缘密度/高频/主色集中度/亮度、水印残留） |
| **B 级软指标** | 只提示（头顶留白、人物头宽比、左右身高一致度） |
| **C 级生成约束** | 人工签收（五官、发丝、锁骨、衣褶、分屏位置不变） |
| **`--scene full`** | 全身镜面自拍模式，改用放宽阈值（`bg_*_full`） |

## 业务

| 词 | 含义 |
|---|---|
| **素材** | 无人工设计叠加的原始照片，可当原料 |
| **成图** | 已带排版/文案/品牌的成品图，只能当版式参考 |
| **版式模板** | 成图的细分类型：可拆结构、套自家内容 |
| **示例口径** | 样张里用的品牌名、价格、参数都是编的，落地必须换真值 |
| **院线** | 美容院渠道（区别于药店、电商） |
| **大屏** | 线下广告位统称（地铁灯箱、商场立柱屏、户外大牌） |
