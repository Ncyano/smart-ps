# 00 · 项目上下文

> **什么时候读**：开局第一件事。
> **一句话**：给 P 图团队做一套「AI 出图 + 代码排版」的批量生产工具，把商品图从接单到交付的周期压下来。

---

## 1. 这是什么

公司 P 图团队（服务护肤/保健类品牌）每天要产出大量电商物料：效果图、价格图、对比海报、线下大屏、尺码表…… 全靠人工，周期长、复用差。

本项目要做的是一个**批量生成 + 审核交付**的应用：

```
设计师上传产品图/参考图/需求文字
        ↓
系统批量生成候选图（AI 出场景 + 代码排版 + 合成）
        ↓
设计师审核 → 局部重做 / 改文案 → 导出
```

**它不是一个"输入一句话出图"的工具。** 它的价值在于：把一套已经验证过的**工艺路线**固化成可批量执行的流程。

## 6. 三个必须记住的约束

**① 模型不画字**
文字全部后置绘制。模型画的字必糊，且会冒出违禁词。

**② 商品主体不能重绘**
保真优先：抠图 + 透明图层合成，不用图生图整图重画。`项目方案.md` §6 已定。

**③ 一切数据照抄素材，不编造**
价格、含量、专利号、检测数据必须来自真实材料。样张里的「示例品牌」「示例价格」「1000mg / 99.9%」全是**示例口径**，落地必须换。
