# 前后对比效果图：生图与交付规则

本技能是本项目（Smart-ps）效果图产线的**执行入口**：负责"按什么顺序做、哪些线不能踩"。规范全本在 `docs/04-效果图制图标准.md`（含标定数据与实现细节），需要追溯依据时再展开；两者冲突时以文档为准。

核心判断只有一句：**这类图翻车的从来不是画质，是"假"。而"假"是可归因、可测量的。**

---

## 何时使用

- 要 AI 生成"使用前/使用后"的人物对比图（变白、减重、体态）
- 已有对比图被反馈"假 / 像拼的 / 像两个 / 不像真人 / 变化不明显 / 变化过大"
- 要修生成图上的平台水印
- 要把两张图合成 1080×1350 双联版式（中缝、标签、合规小字）
- 要审核一批效果图是否达标

不适用于：纯产品图、海报表格排版（那套是 HTML+CSS+Playwright 截图，见 `产出/海报/`）。

---

## 先确认的输入

| 输入 | 位置 | 用途 |
|---|---|---|
| 素材例子 | `素材例子/制作不同期限…还有减肥产品等/` | **幅度与构图的标定基准**，不能凭感觉 |
| 竞品/参考版式 | `素材例子/根据表格产品对比详细维度做成精美海报形式/` | 版式与维度参照 |
| 生成源图 | `产出/ai人物/real*/` | 每次生成进新目录，不覆盖旧版 |
| 合成脚本 | `产出/效果图/_build.py` | 版式、标签、合规文案 |
| 质检器 | `scripts/check_compare.py` | 硬指标拦截 |
| 阈值 | `config/config.toml` 的 `[compare]` 段 | 改配置即改口径，不改代码 |

品类先问清：**化妆品（只能脸部变白）／保健食品（脖子身体可变白）／减重**。三者合规文案和天数都不同。

## 工作流

### ① 先标定，再生成

有素材就量素材，不要凭感觉设参数。减重必须按 `docs/04 §5.5` 的方法量出各高度带宽度比，选定"温和档/明显档"。背景类需求先确认参考图里允许保留什么。

### ② 生成：两段式提示词

顺序是**先锁后改**：先列死所有不许动的，再只给一个改动方向，只用一个 `ONLY`。模板见 `references/prompt-templates.md`。

`input_fidelity` 的选择是硬规则：

| 目标 | fidelity | 说明 |
|---|---|---|
| 只换背景，人物必须一模一样 | `high` | 几乎不动人物 |
| 需要实质改变体型/肤色 | `medium` | 唯一能用的一档 |
| — | `low` | **禁用**：会把左半、脸、衣服一起重画 |

尺寸 `1024x1536`（双联竖构图）、`quality=high`、每次输出到新目录 `real3/ real4/ …`。

### ③ 量化，不靠肉眼

生成完立刻量，量完再决定是否重做。命令：

```bash
python scripts/check_compare.py --src 产出/ai人物/realN/xxx.png
```

源图模式会跳过版式项（还没合成），只测背景与水印。

### ④ 修水印（生成图几乎必带）

只有一种干净做法：**取水印区正上方、同宽同高的纹理回补** → 整体均值对齐 → 左侧和上方羽化 → 叠 1.5 噪声。

三条禁令（每条都实际翻过车）：不准 `cv2.inpaint`（留糊斑）、不准从左侧取纹理（会把脚趾一起复制，出现第二双脚）、不准裁掉底部（切脚）。

细节与代码在 `references/pitfalls.md`。

### ⑤ 合成

改 `产出/效果图/_build.py` 的 `JOBS`：`path` 指源图、`ypos` 调垂直取景、`tag` 决定标签在上还是下、`scene` 选背景阈值档位。然后单张重建：

```bash
python 产出/效果图/_build.py slim
```

合成后会自动调质检器并打印结果。

### ⑥ 质检必过才交付

```bash
python scripts/check_compare.py 产出/效果图/body.png              # 近景档
python scripts/check_compare.py --scene full 产出/效果图/slim.png  # 全身镜面档
```

退出码 0 才算过。硬指标任何一项 FAIL 都不能交付。

**报告超标前先验证测量本身。** 同一张图两半用 GrabCut 能量出 130px 的头顶差，报出来的"身高差 11.7%"是分割漂移，不是图的问题。先打印中间量，确认检测器没错，再改图。

## 铁律（每条都对应一次真实翻车）

1. **真实感 ≠ 元素多。** 背景越干净，穿帮面越小。近景用一面浅米白墙（`#EDE9E4`）+ 柔光衰减 + 极淡纹理；为了"生活感"塞衣柜、床、台灯，两半家具对不上，反而暴露拼接。
2. **背景不是纯白影棚，也不是无缝背景纸。** 提示词必须写 `NOT a studio backdrop` + `slightly uneven and real`，墙面留一点不完美。
3. **两半必须是同一间房、同一面墙。** 写 `both halves must read as the same wall in the same room`，否则模型会各生成一面。
4. **人物是同一人，不是"同款人"。** 脸型、眼距、鼻型、发际线、耳、发丝走向、衣褶位置全部锁死。削下巴、瘦鼻、美颜滤镜一律算不合格。
5. **不要做镜像对称。** 两半允许轻微不对称；完美对称是拼接最明显的破绽。
6. **否定式只挡具体缺陷，不用来挡"变化"本身。** 写 `no ab lines / no six-pack / no visible ribs / no hip bones / no chin sharpening` 是对的；写 `do not make the legs skinny` 会把正常减重一起禁掉，结果只有腰在变——比幅度过大更像修图。
7. **必须分部位逐条写目标状态。** 只给一个总减重量（"lost 8-10 kg"），模型会自由发挥，通常只动腰腹。
8. **幅度按素材分档，不跨档混用。** 温和档配 2–3 个月文案，明显档配 3–4 个月；用明显档幅度配"一个月"是失真组合。
9. **左右必须同尺度。** 头顶线差 ≤ 0.03（画布高）。旧版差 17% 的观感就是"相机被拉近"，比轮廓错误更致命。
10. **合规文案按品类固定，一字不改。** 不写具体斤数/厘米数，只写使用前/后 + 天数。
11. **数据不编造。** 海报里的数值照抄原表；口径不同（礼盒价 vs 单瓶价、标示值 vs 上限值）必须单独标注，不能直接并排比较。
12. **不交付没跑质检的图。** "看起来还行"不是通过标准。

## 交付前检查

- [ ] 源图背景四项指标全过（近景 `edge≤0.025` `hf≤5.0`；全身 `≤0.055` `≤6.0`）
- [ ] 水印近白笔画 ≤ 0.02，且肉眼确认右下角干净、地板/墙面纹理连贯
- [ ] C 层 8 条人工签收：五官、发丝、锁骨、衣褶、裁切、冷暖差、无美颜、非镜像
- [ ] 减重图：各高度带变化率落在目标档区间，全身均值与文案周期匹配
- [ ] 左右头顶线差 ≤ 0.03
- [ ] 标签不压脸、不压锁骨、脚完整
- [ ] 合规文案与品类匹配
- [ ] `check_compare.py` 退出码 0
