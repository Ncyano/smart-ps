# 质检口径与阈值

阈值全部在 `config/config.toml` 的 `[compare]` 段，代码不写死任何数字。改配置即改口径。
检测器：`scripts/check_compare.py`，退出码 0 = 全通过，1 = 有硬指标不合格。

---

## 三层判定

| 层 | 内容 | 谁判 | 不通过后果 |
|---|---|---|---|
| **A 硬指标** | 画布、中缝、背景洁净度、水印残留 | 检测器自动 | 不可交付 |
| **B 软指标** | 头顶留白、左右头顶线差 | 自动算数 | 提示，不拦截 |
| **C 生成约束** | 五官/发丝/锁骨/衣褶/分屏位置 | 人工逐条签收 | 重生成 |

---

## A 层

### 版式

| 项 | 值 |
|---|---|
| 画布 | 1080 × 1350（4:5 竖版） |
| 中缝 | 5px 纯白，中心 x∈[536,541]，容差 4–6px |
| 左右半 | 537 / 538 |
| 输出 | JPEG q95，**单倍直出** |

不做 2 倍渲染：源图只有 1024 宽，放大后人物发虚，反而更假。

### 背景洁净度

**探针区**：切缝后每半取 5 个框——四角各 22%×22% + 顶部 100%×16%，10 框取平均。这四个位置人物不可能占到，因此**不需要语义分割**就能取到纯背景样本。

只取顶部条带会漏测家具（v3 顶部是天花板，测不出衣柜）。

| 指标 | 定义 | 近景 `closeup` | 全身 `full` |
|---|---|---|---|
| `edge_ratio` | Sobel > 24 的像素占比 | ≤ 0.025 | ≤ 0.055 |
| `hf` | Sobel 幅值均值 | ≤ 5.0 | ≤ 6.0 |
| `top1` | RGB 量化 32 级后最大同色占比 | ≥ 0.12 | ≥ 0.10 |
| `p50` | 亮度中位数 | 80–210 | 80–210 |

四项取**与**。`edge` 和 `hf` 不可互替：v3 的 edge 只有 0.017 看着合格，hf 5.60 才把它卡住——虚化的家具边缘能量还在。

分档原因：全身镜面自拍的背景天然有衣柜门缝、踢脚线、地板缝，这些是真实现场，不是"假"。放宽的只是结构性线条，**大件家具和品牌标识仍然禁止**（人工判）。

### 水印残留

用**近白细笔画占比**，不用边缘密度（衣服褶皱的边缘密度比水印还高，会误报 0.084）。

```
wm  = 右下角 [0.85w,0.92h → w,h] 内 min(R,G,B) > 205 的占比
up  = 同列正上方同尺寸区域的同一比值
通过：wm ≤ 0.02 且 wm ≤ up×2 + 0.005
```

## B 层

| 指标 | 定义 | 区间 |
|---|---|---|
| 头顶留白 | 按列取背景基线，逐行找第一个非背景行 ÷ 画布高 | 8%–18% |
| 左右头顶线差 | `|y_head_R − y_head_L|`（画布高比例） | ≤ 0.03 |

**头顶留白不能用单一中位数当背景色**：墙面横向有光照渐变，第一行一半偏亮一半偏暗，中位数距离会让一半像素超阈值，直接误判为 0。必须 `np.median(a[:bh], axis=0)` **按列取基线**。

**头顶线不要用 GrabCut**：同一张图两半、同一套参数能差出 130px，报出来的"身高差"是分割漂移。改为中列 28%–72% 带宽内，找第一个「连续 ≥10 行、暗像素占比 >2%（L<95）」的位置；衣柜顶沿这类水平细线只有几行，会被 minrun 排掉。

---

## 阈值怎么来的

在 5 个已知好坏的样本上实测，取能分开好坏的线，不是拍的：

| 样本 | edge | hf | top1 | p50 | 判定 |
|---|---|---|---|---|---|
| v1 复杂背景 | 0.054 | 6.86 | 0.173 | 147.9 | ✗ |
| v3 家居背景 | 0.017 | 5.60 | 0.123 | 99.7 | ✗ |
| **v5 干净墙面** | **0.007** | **3.40** | **0.172** | **130.4** | **✓** |
| face 旧版 | 0.023 | 5.64 | 0.061 | 146.6 | ✗ |
| slim 旧版 | 0.041 | 5.47 | 0.126 | 170.1 | ✗ |

`edge=0.025` / `hf=5.0` 正好把定稿版与其余四例分开。样本只有 5 例，每新增一类场景（深色墙面、强渐变、户外）应回归一次本表。

## 减重视图的专项口径

| 档位 | 减重跨度 | 躯干 | 大腿 | 小腿 |
|---|---|---|---|---|
| 温和档 | 8–10 kg | −5 ~ −13% | −6 ~ −15% | −5 ~ −12% |
| 明显档 | 12–15 kg | −13 ~ −17% | −17 ~ −22% | −16 ~ −20% |

客户给具体数字（如"大概 15%"）时，按 **11 个高度带（0.38–0.88）的算术平均**对齐，允许 ±3 个点。生成模型会系统性偏高 2–3 个点，按均值对齐即可，不必为了卡准重生成——重生成有丢脸、丢腰腹柔软感的风险。

测量方法：`cv2.grabCut` 矩形初始化 → 最大连通域 → 头顶到脚底为身高 `hh` → 各相对高度行宽 ÷ `hh`。逐行自适应背景色会失败（墙面横向渐变、地板色差导致 mask 铺满全宽）。

## 命令

```bash
# 成品（交付前必跑）
python scripts/check_compare.py 产出/效果图/body.png
python scripts/check_compare.py --scene full 产出/效果图/slim.png

# 生成源图（未合成，跳过版式项）
python scripts/check_compare.py --src 产出/ai人物/realN/xxx.png

# 机器可读，接 CI / 产线⑥质检
python scripts/check_compare.py 产出/效果图/body.png --json
```

单张重建：

```bash
python 产出/效果图/_build.py slim
```

`JOBS` 每项支持 `path`（单独指定源图）、`ypos`（垂直取景）、`tag`（标签在上/下）、`tag_y`、`scene`、`days`、`legal`。
