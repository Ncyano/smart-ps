# 前后对比效果图：量化制图标准

日期：2026-11-20　适用：`产出/效果图/` 全系列（面部变白 / 颈部身体变白 / 减重塑形）
配套：[自动 P 图产线设计](03-自动P图产线设计.md)、检测器 `scripts/check_compare.py`、配置 `config/config.toml` 的 `[compare]` 段

---

## 0. 为什么需要这份标准

这类图最容易翻车的不是画质，是**"假"**。而"假"是可归因的，每一条都能落到一个可测量的物理量上：

| 用户原话 | 真正的技术原因 | 可测量 |
|---|---|---|
| "背景复杂导致场景虚假" | 左半有木衣柜、右半是床，两半家具对不上、透视不一致 | 背景区域的边缘密度、高频能量、主色集中度 |
| "一眼看出是拼的" | 两半光比、色温、人物尺寸差异过大 | 背景亮度带、头顶留白、人物头宽比 |
| "像 AI 不像真人" | 过度锐化、无噪点、皮肤零毛孔 | 高频能量上限、噪点方差下限 |
| "卖点被挡了" | 标签压脸、裁切切锁骨 | 标签与人脸区的重叠、头顶留白 |

一句话：**真实感不等于元素多，等于不穿帮。** 背景越干净，穿帮面越小。上一版为了"生活感"塞了衣柜、床、台灯、洗衣篮，结果两半家具位置对不上，反而暴露了拼接。定稿方向是一面浅米白墙 + 柔和光衰 + 极淡纹理。

---

## 1. 三层判定模型

不能指望全部自动判定，也不能全靠肉眼。分三层，各管各的：

| 层 | 内容 | 判定方式 | 不通过后果 |
|---|---|---|---|
| **A 硬指标** | 画布、中缝、背景洁净度、水印残留 | `check_compare.py` 自动 | 不可交付，必须重做 |
| **B 软指标** | 头顶留白、背景亮度观感 | 自动算数，人工定夺 | 提示，不拦截 |
| **C 生成约束** | 五官/发丝/锁骨/衣褶/分屏位置不变 | 逐条人工签收（§5 清单） | 重生成 |

阈值全部集中在 `config/config.toml` 的 `[compare]` 段，改配置即改质检口径，代码里不写死任何数字。

## 2. A 层：硬指标

### 2.1 版式（A1）

| 项 | 量化值 | 说明 |
|---|---|---|
| 画布 | `1080 × 1350` px | 4:5，信息流竖版 |
| 中缝 | `5` px 纯白，中心 x∈[536, 541] | 容差 4–6px（JPEG 会有半像素） |
| 左半 / 右半 | `537` / `538` px | 差 1px 是取整，不做补偿 |
| 输出 | JPEG q95 | 单倍输出，不做 2 倍缩放 |

> 反例留档：早期用 `poster` 那套 2 倍渲染（2160×2700），源图只有 1024 宽，放大后人物发虚，反而更假。1 倍直出更接近手机照片观感。

### 2.2 背景洁净度（A3）—— 本标准的重点

**探针区定义**（避开人物，只测背景）：

1. 先用中缝把图切成左右两半；
2. 每半图取 5 个探针框：**四个角各 22%×22%** + **顶部 100%×16%**；
3. 10 个探针框取算术平均。

四个角 + 顶部是人物最不可能占到的位置，因此不需要语义分割就能稳定取到"纯背景"样本。

#### 分场景两档阈值

一刀切会误伤：近景（面部/颈肩）背景必须极简，但全身镜面自拍的背景天然包含衣柜门缝、踢脚线、地板缝，这些不是"假"，是真实居家场景。所以分两档，用 `--scene` 切换：

| 指标 | 近景 `closeup`（默认） | 全身镜面 `full` |
|---|---|---|
| `edge_ratio` | ≤ 0.025 | ≤ 0.055 |
| `hf` | ≤ 5.0 | ≤ 6.0 |
| `top1` | ≥ 0.12 | ≥ 0.10 |
| `p50` | 80 – 210 | 80 – 210 |

全身档放宽的是"结构性线条"（门缝、踢脚线、地板拼缝），**大件家具和品牌标识仍然禁止**，这一条靠人工判（§5 C 层）。

| 指标 | 定义 | 阈值 | 超标的物理含义 |
|---|---|---|---|
| `edge_ratio` | Sobel 幅值 > 24 的像素占比 | 见上表 | 背景里出现家具轮廓、门缝、杂物边缘 |
| `hf` | Sobel 幅值均值 | 见上表 | 背景有纹理（木纹、布料、瓷砖、地板） |
| `top1` | RGB 量化到 32 级后最大同色占比 | 见上表 | 色块分散 = 不是一面墙 |
| `p50` | 探针区亮度中位数 | **80 – 210** | 过高=纯白影棚感，过低=暗房 |

四项是**与**关系，任一项超标即不合格。`edge` 和 `hf` 不能互相替代：家具的边缘可能被虚化，但纹理能量还在。

### 2.3 水印残留（A4）

平台图生图会叠加右下角水印。判定用**近白细笔画占比**，不用边缘密度：

```
wm_ratio = 右下角 [0.85w, 0.92h → w, h] 内 min(R,G,B) > 205 的像素占比
up_ratio = 同列正上方同尺寸区域的同一比值
判定：wm_ratio ≤ 0.02，且 wm_ratio ≤ up_ratio × 2 + 0.005
```

用"近白"而不是"边缘密度"，是因为衣服褶皱、皮肤纹理的边缘密度也很高，会误报（实测 face 图右下角衣服被判成水印，比值 0.084，改用近白后归零）。

**修补方法**（已知唯一干净的做法）：取水印区**正上方同宽**的纹理回补，14–16px 羽化，回补前做亮度均值对齐 `patch × (region.mean() / patch.mean())`，最后叠 1.6 的噪声。

三种错误做法留档：`cv2.inpaint` 大块留糊斑；从左侧取纹理会把脚趾一起复制过去（出现第二双脚）；直接裁掉底部会把脚切了。

## 3. B 层：软指标

| 指标 | 定义 | 期望区间 | 处理 |
|---|---|---|---|
| 头顶留白 (B2) | 按列取背景基线，逐行找第一个非背景行 ÷ 画布高 | **8% – 18%** | 偏大调 `ypos` 收紧，偏小放松取景 |
| 人物头宽比 | 左右两半头部宽度之比 | **0.85 – 1.18** | 超差说明像两个人，需统一缩放重做 |

`B2` 在特写/全景构图（头顶出画）时自动标 N/A。判定方式是"第一行就是非背景"，此时留白指标无意义。

**头顶留白算法的坑**：不能用单一中位数当背景色。墙面横向有光照渐变，第一行会出现一半偏亮一半偏暗，中位数距离算出来一半像素超阈值，直接误判为 0。必须**按列取基线**（`np.median(a[:bh], axis=0)`），才能吸收横向渐变。

## 4. 阈值是怎么来的（标定数据）

阈值不是拍的，是在 5 个已知好坏的样本上测出来再取分界的：

| 样本 | edge | hf | top1 | p50 | 人工判定 |
|---|---|---|---|---|---|
| v1 早期复杂背景（衣柜+杂物+水印） | 0.054 | 6.86 | 0.173 | 147.9 | ✗ 假 |
| v3 家居背景（衣柜+床+台灯） | 0.017 | 5.60 | 0.123 | 99.7 | ✗ 用户判假 |
| **v5 定稿干净墙面** | **0.007** | **3.40** | **0.172** | **130.4** | **✓ 可交付** |
| face 旧版 | 0.023 | 5.64 | 0.061 | 146.6 | ✗ 待统一 |
| slim 全身版（洗衣篮+地板+门框） | 0.041 | 5.47 | 0.126 | 170.1 | ✗ 待统一 |

取 `edge=0.025` / `hf=5.0` 作分界，正好把 v5 与其余四例分开（v5 edge 0.007、hf 3.40，均为全场最低）。注意 v3 的 `edge` 只有 0.017，看着像合格，但 `hf` 5.60 超线——这就是两项必须取"与"的原因。

复跑验证（`check_compare.py`）：

```
v5 干净墙面源图      8/8 通过
v3 家居背景源图      7/8（背景高频不合格）
v1 复杂背景源图      5/8（背景边缘、背景高频、水印残留不合格）
定稿 body.png 成品   8/8 通过
```

> 局限：只有 5 例标定，样本偏少。阈值对"墙面渐变很强"或"大面积深色墙面"的场景可能偏严，后续每新增一类场景应回归一次这张表。

## 5. C 层：生成约束（不可自动判定，人工签收）

以下每条都对应一次实际翻车，必须逐条过：

| # | 约束 | 违反后果 |
|---|---|---|
| C1 | 五官骨相、脸型、眼距、鼻型不变 | 左右像两个人 |
| C2 | 发丝落在肩上的走向不变，不新增/减少发束 | 一眼看出换人 |
| C3 | 锁骨线条完整，不被头发遮住一半 | 颈部是卖点，遮住=白做 |
| C4 | 白色背心的褶皱位置不变 | 衣服变了=另一张照片 |
| C5 | 裁切框、中缝位置、相机高度不变 | 构图漂移 |
| C6 | 保留左右原有冷暖差异（不强行统一白平衡） | 统一了反而假，真实前后对比本来就不同光 |
| C7 | 无美颜滤镜痕迹：保留毛孔、细小瑕疵、轻微噪点 | 过度平滑 = AI 塑料感 |
| C8 | 不做"完美镜像对称"，两半允许轻微不对称 | 镜像对称是拼接最明显的破绽 |

### 提示词写法：两段式

顺序很重要——**先锁后改**。先列死所有不许动的，再只说背景，只用一个 `ONLY`，不要给模型第二个改动方向。

```
Edit this photo.

KEEP EXACTLY UNCHANGED: both faces, facial features, expressions, hairstyles,
hair strands on the shoulders, body posture, neck and collarbone shape, the white
cotton tank top with its exact folds, the framing and crop, the vertical split
position between the two halves, and the warm-vs-cool skin tone difference.

ONLY replace the background.

New background: one single plain clean wall in very light warm grey-beige
(#EDE9E4), completely empty — no wardrobe, no bed, no headboard, no bedside table,
no lamp, no bottles, no clothes, no clutter, no door frame, no window. A smooth
soft wall with gentle natural light falloff toward the corners and a barely
visible texture. It must NOT look like a studio backdrop, NOT pure white, NOT a
gradient template — it looks like an ordinary bedroom wall at home, slightly
uneven and real. Both halves must read as the same wall in the same room.

Authentic casual smartphone front-camera selfie quality: mild sensor noise,
slight softness, natural real skin with visible pores, no beauty filter, no skin
smoothing, no studio lighting, no ring light, no HDR glow, no added vignette.
```

参数：`input_fidelity = high`、`size = 1024x1536`、`quality = high`。

关键三句：`NOT a studio backdrop`（否则出无缝背景纸）、`slightly uneven and real`（墙面必须留一点不完美）、`both halves must read as the same wall in the same room`（防两半各生成一面墙）。

### 背景元素白名单 / 黑名单

| | 内容 |
|---|---|
| **允许** | 单色墙面、柔光衰减、极淡墙面纹理、墙角阴影 |
| **禁止** | 家具（衣柜/床/床头柜/桌子）、灯具、电器、挂画、门框、窗框、衣物、瓶罐、地板、拖鞋、洗衣篮、插座、任何可辨认品牌标识 |

克制的原因：每多一个物体，左右两半就多一次"对不上"的机会。

## 5.5 减重幅度的量化标定（slim 图专用）

全身减重对比最容易翻车的地方不是画质，是**幅度**。用户原话："前后差异过大"。实测确认：旧版左右轮廓差 25–50%，而素材最大跨度（减 30 斤）也只有 5–25%。

### 标定方法

不靠目测。对素材图逐档分割人物轮廓，量**各高度带的宽度 ÷ 人物像素身高**，得到与分辨率、缩放无关的体型比率：

1. `cv2.grabCut` 矩形初始化粗分割 → 取最大连通域；
2. 人物头顶到脚底为身高基准 `hh`；
3. 在相对高度 0.22 / 0.30 / 0.38 / 0.46 / 0.55 / 0.65 / 0.75 / 0.85 处量该行前景宽度，除以 `hh`；
4. 两档相除得变化率。

### 素材标定结果

素材 `素材例子/…减肥产品等/8873cab2…jpg`，同一人三档体重、同机位镜面自拍：

| 高度带 | 部位 | 130→110 斤 | 130→100 斤 |
|---|---|---|---|
| 0.22 | 肩/上胸 | −5.5% | −10.3% |
| 0.30 | 腰腹 | −8.4% | −13.1% |
| 0.46 | 臀 | −10.2% | −11.6% |
| 0.55 | 大腿根 | −13.0% | −7.5% |
| 0.65 | 大腿中 | −6.5% | −25.3% |
| 0.85 | 小腿 | −6.0% | −17.1% |

两条结论：

1. **躯干正面的宽度变化其实很温和**（−5~13%）。减肥的视觉冲击主要来自"侧面厚度减小"和"腿部变细"，不是正面变窄。
2. 减 20 斤档的腿部只降 6–13%，减 30 斤档才到 17–25%。**跨度选错，图就假**。

### 我们的目标区间

幅度按 `DAY 0 → DAY 84` 分两档，由文案里的减重跨度决定，不能混用：

| 档位 | 对应减重 | 躯干 | 大腿 | 小腿 | 适用 |
|---|---|---|---|---|---|
| 温和档（素材 130→110） | 约 8–10 kg | −5% ~ −13% | −6% ~ −15% | −5% ~ −12% | 短期/保守表述 |
| 明显档（素材 130→100） | 约 12–15 kg | −13% ~ −17% | −17% ~ −22% | −16% ~ −20% | 四个月、客户要求"看得出变化" |

客户口径若给出具体数字（例如"大概 15%"），按**全身平均变化率**对齐：以 11 个高度带（0.38–0.88）的算术平均为准，允许 ±3 个百分点。

### 实测对比

| | 躯干 | 大腿 | 小腿 | 全身均值 | 左右头顶线差 |
|---|---|---|---|---|---|
| 旧版（v1） | −25.4% ~ −49.3% | −20.5% ~ −31.6% | −24.1% ~ −26.1% | — | **17.2%** |
| 中间版（v5） | −8.7% ~ −10.0% | −7.6% | −9.0% ~ −12.3% | — | 4.5% |
| v8（温和档定稿） | −7.7% ~ −9.5% | −13.2% ~ −14.0% | −13.2% ~ −15.4% | ≈ −11% | **0.2%** |
| **v9（明显档定稿）** | **−16.0% ~ −18.8%** | **−18.1% ~ −19.5%** | **−17.2% ~ −20.2%** | **≈ −17%** | **0.1%** |
| 素材 130→110 | −5.5% ~ −13.0% | −6.5% ~ −13.0% | −6.0% | ≈ −8% | 5%（三档间） |
| 素材 130→100 | −10.3% ~ −14.4% | −17.0% ~ −26.1% | −16.7% ~ −25.0% | ≈ −17% | 5% |

旧版躯干超出目标上限 2–4 倍，腿部超出约 2 倍，且人物尺度差 17%——两个错误叠加，就是"像换了个人"。

### 只改幅度不够：分布必须连续覆盖全身

v5 把幅度收到 −8~10% 后，用户仍不满意，原话是"大部分变化不明显且只有部分区域变化，不太符合人体"。实测确认了原因：

| 高度带 | v5 实测 | 素材 130→100 | 问题 |
|---|---|---|---|
| 肩/上胸 0.22–0.30 | −2.0 ~ −6.0% | −10 ~ −13% | 几乎没动 |
| 腰腹 0.38–0.46 | −8.7 ~ −10.0% | −4 ~ −11% | 只有这一段在变 |
| 大腿 0.66–0.74 | **−7.6%** | −21 ~ −26% | 几乎没动 |
| 小腿 0.86–0.90 | −9 ~ −12% | −18 ~ −25% | 偏小 |

腰腹变了、肩和腿没变，结果是"腰被夹窄"，反而比幅度过大更像修图。**素材的规律是越往下变化越大**（腿最多），v5 恰好是反的。

而且这不是模型的问题，是提示词写反了：v5 的提示词里写着 "Thighs should stay normally thick — do not make the legs skinny"，等于主动禁止腿部变化。改成逐部位写明目标后（明确要求"大腿要有可见间隙、小腿变细"），分布立刻对上。

对应的两条写作规则：

1. **分部位逐条写目标状态**，不要只给一个总减重量。只写 "lost 8-10 kg"，模型会自由发挥，通常只动腰腹。
2. **不能用笼统的否定式挡住所有变化**。"do not make legs skinny" 会连带禁掉正常幅度的变化，削弱过头就变成局部修图。否定式只用来挡"过度瘦化"的具体特征（no ab lines / no six-pack / no visible ribs / no hip bones），不用来挡"变瘦"本身。

### 左右尺度一致（B3）

比轮廓更隐蔽的破绽：两半人物在画面里不一样高。旧版右半比左半高 17.2%，等于相机被拉近了。素材三档之间只差 5%。

判定：`|y_head_right − y_head_left| ≤ 0.03`（画布高比例）。这项只在 `--scene full` 时计算。

**头顶线用"连续深色行"检测，不要用 GrabCut**。GrabCut 在本场景下会随 GMM 初始化漂移：同一张图的两半，同一套参数能差出 10% 以上（实测左半 top=204、右半 top=335），报出来的"身高差"其实是分割误差；加种子初始化也压不住。改用中列一带（28%–72%）找第一个「连续 ≥10 行深色占比 >2%」的位置，衣柜顶沿这类水平细线只有几行，会被 minrun 自然排掉。同一批图实测：合成图左 205 / 右 207、v8 源图两半完全相等、v9 源图差 0.7%。

历史：B3 最初用 GrabCut 量人物像素高度，阈值 0.06；因上述漂移，一度把正常图报成 15.7% 超标。改为头顶线后阈值收紧到 0.03，语义也更直接——脚踩在同一地平线（合成时两半等比 cover 到同高），头顶线差就等于身高差。

### 提示词为什么不能只写"减重 10 斤"

实测两轮，只写重量或只写 "lose 8-10kg" 都没用，模型仍往"健身博主"方向画。有效的写法是**逐部位描述目标状态**，且全部用否定式堵住过度瘦化：

```
RIGHT panel: ordinary healthy woman who has lost only a little —
- belly: still soft and slightly rounded, a small natural pooch,
  no ab lines, no six-pack, no visible ribs or hip bones
- waist: only slightly narrower than her hips, not a defined hourglass
- thighs: thick and nearly touching at the top, no gap between upper
  thighs, normal leg thickness relative to torso, normal leg length
- arms: normal soft arms, not thin sticks
- face: same face shape as LEFT, cheeks still full, only marginally
  less puffy. No chin sharpening, no nose slimming.
```

外加一条独立的强约束：`both figures must be exactly the same height in the frame, same distance from the mirror`。

另外 `input_fidelity` 要取 `medium`：`high` 会几乎不动（幅度仍是旧值），`low` 会连左半和脸一起重画。

## 6. 版式与文案

### 6.1 叠字

| 元素 | 字号 | 描边 | 位置 |
|---|---|---|---|
| 标签「使用前 / 使用后」 | 40px 粗体（msyhbd） | 3px 纯黑 | `anchor="mm"`，底图版 y=H−116，顶图版 y=82 |
| 天数「DAY 0 / DAY 28」 | 17px 粗体 | 2px | 距标签 ∓42px（底部版在上方，顶部版在下方） |
| 合规小字 | 13px 常规（msyh） | 2px `#282828` | y=H−26，居中 |

居中一律用 `anchor="mm"`。手工算 `textbbox` 再偏移会偏 2–4px，不同字数偏移量还不一样。

### 6.2 合规文案（按品类固定，不得改写）

| 品类 | 文案 |
|---|---|
| 面部护肤（化妆品） | `AI 生成对比示意图 · 实际效果因人而异 · 本品为化妆品，不具备医疗功效` |
| 保健食品 | `AI 生成对比示意图 · 实际效果因人而异 · 本品为普通食品，不具有疾病预防、治疗功能` |
| 减重塑形 | `AI 生成对比示意图 · 实际效果因人而异 · 配合规律饮食与运动` |

天数口径：护肤 28 天、保健 28 天、减重 84 天。**不写具体斤数/厘米数**，只写使用前/后 + 天数。

## 7. 执行

```bash
# 成品交付前必跑（不合格项即阻断）
python scripts/check_compare.py 产出/效果图/body.png 产出/效果图/face.png
python scripts/check_compare.py 产出/效果图/slim.png --scene full   # 全身镜面档

# 生成源图（未合成）跳过版式项
python scripts/check_compare.py --src 产出/ai人物/real3/body_clean.png

# 机器可读，便于接入产线
python scripts/check_compare.py 产出/效果图/body.png --json
```

退出码：全通过 0，有硬指标不合格 1。可直接挂到 CI 或产线的⑥质检环节。

重建合成：

```bash
python 产出/效果图/_build.py body    # 只重建单张
python 产出/效果图/_build.py         # 全部重建
```

`_build.py` 的 `JOBS` 里每项支持 `path`（单独指定源图）、`ypos`（垂直取景）、`tag`（标签在上/下）、`days`。
