## 0. 先看硬约束：本机没有 GPU

| 项 | 实测值 |
|---|---|
| CPU | Intel Core i5-12600K（10C16T） |
| 显卡 | Intel UHD Graphics 770（核显，无 CUDA） |
| 系统 | Windows，Node 24.21 / Python 3.13 |

**结论**：SDXL / FLUX / Qwen-Image 这类扩散模型本地跑不动（fp8 也需 8–24GB 显存，核显只有共享内存，速度按分钟计）。所以：

- **生成式能力必须走云 API**（或租 GPU 自建）；
- **本地只放轻量确定性算子**（抠图、擦除、放大、几何校正），ONNX Runtime CPU 秒级可跑，边际成本为 0。

这条约束不改变"能不能做"，只改变"哪部分放本地"。

## 1.1 重点：Seedream 5.0 Flash（默认档候选）

模型 ID `doubao-seedream-5-0-flash`，2026-09 发布，属 Seedream 5.0 家族里的"快速档"（与 Pro / Lite 并列）。

| 项 | 值 |
|---|---|
| 能力 | 文生图 + **单图 / 多参考图编辑**（最多 10 张参考）+ 精准编辑 + **图层拆分** + **透明背景输出** |
| 分辨率 | 1K / 1.5K / 2K，每档 8 种宽高比 |
| 计费 | **固定费率 0.12 元/张**（七牛渠道），BytePlus $0.018/张（≈0.13 元）—— 选哪个分辨率都是同一个价 |
| 输出 | 每次 1 张（无批量/多张候选） |

**为什么它适合"智能 PS"**：

1. **透明背景输出**——修图工具最刚需的出口格式，省掉单独抠图链路的一半工作。
2. **10 张参考图**——把"商品图 + 模特图 + 场景图 + 风格图"一次喂进去做合成，这是 Pro 之外的差异点。
3. **生图与编辑同一个模型/同一条指令语法**——工具里的"重绘"和"新建"可以共用一个适配器。
4. **0.12 元固定价**，比 Pro 便宜 60%，交互式反复试错的成本可以忽略。
5. **图层拆分**——从一张平面图还原成可编辑图层，是"PS 感"最强的能力。

**代价**：Flash 档的质感与细节弱于 Pro，复杂中文文字、精细材质、人物一致性都会掉一档；上限 2K。所以定位是**默认档**，不是最强档。

## 3. "智能"这一层：VLM 规划 + 工具调用

智能 PS 与"AI 修图网站"的真正区别在于**听懂人话并拆步骤**：

```
用户："把背景换成办公室，人别动，脸保留原样，再亮一点"
        ↓  VLM 解析（Qwen3-VL-Plus，输入 1 元/百万 token）
结构化编辑计划 JSON：{ mask: 背景, op: 重新生成, prompt: 办公室, protect: [人脸], post: +0.3EV }
        ↓  执行器
本地 CV（抠图/蒙版） → 云模型（重绘） → 本地 CV（融合/调色） → 回显
```

- 规划模型推荐 Qwen3-VL-Plus（便宜、中文强、能看图）；不够时上 GPT / Gemini 做兜底。
- 计划必须是**结构化 JSON**，可预览、可撤销、可单步重跑——这是"专业工具"与"抽卡"的分水岭。

## 4. 推荐组合（三档）

| 档位 | 组成 | 单次成本 | 适用 |
|---|---|---|---|
| **A. 最小可用** | 本地 CV + Seedream Flash 单引擎 | **0.12 元** | 本周能跑通验证 |
| **B. 推荐默认** | 本地 CV 打底 + 三档路由：默认 Flash（0.12），成品切 Pro（0.3），中文文字切 Qwen 3.0（0.25）；GPT/Nano 作为"高清修复"开关 | **0.12–0.5 元** | 上线形态 |
| **C. 规模化** | 租 GPU + FLUX.2 [dev] / Qwen-Image-Edit 自建 | 0.05–0.15 元 + 运维 | 日单量上千或需私有化 |

**建议从 A 起步、B 上线、按量决定是否下沉到 C**：全程无需 GPU、无需运维，换模型只改一个适配层。Flash 把默认成本压到 0.12 元后，"让用户先点一下看看"在产品上才成立。

## 5. 技术栈倾向（待形态确认后定稿）

- **独立 Web 应用**：React + Canvas/Konva（图层、蒙版、历史栈）+ Python FastAPI 后端 + 任务队列；ONNX 本地算子走 sidecar 进程。
- **Photoshop 插件**：UXP 插件（面板 UI）+ 本地 companion 服务（跑 ONNX 与转发云 API）——纯 UXP 做不了本地推理。
- **桌面应用**：Tauri/Electron 壳 + 同样的本地服务。

三者共用同一套「编辑计划 → 执行器 → 模型适配层」内核，形态只影响外壳。

## 6. 需要你拍板的问题

1. **形态**：Photoshop 插件 / 独立网页工具 / 桌面软件？（决定外壳与分发）
2. **用户与合规**：只自己用，还是对外提供服务？国内还是海外？（决定能否用 OpenAI / Google）
3. **量级与预算**：每天大概处理多少张？愿意按量付费，还是买/租一台 GPU？
4. **优先级**：先做哪三个功能？（抠图换背景 / 局部重绘 / 证件照 / 批量调色 / 文字改写 / 老照片修复…）
